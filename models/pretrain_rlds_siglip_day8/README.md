# Multi-view + Temporal Contrastive Pretraining — proj_head.pt

> Sprint Day 8 deliverable · 2026-05-17 · `lz-googlefycy/vla-lab`

A 656K-param projection head trained on top of frozen SigLIP-so400m vision
features with **dual-stream InfoNCE** (multi-view + temporal). Maps
SigLIP's 1152-d image features to 128-d L2-normalized embeddings where:

- agent view and wrist view of the **same timestep** are pulled close
- agent view at time `t` and time `t+5` are pulled close
- across-batch / across-task pairs are pushed apart

This is the **deliverable for resume Bullet 1** ("设计并实现 双流 InfoNCE
多视角时空对齐预训练（SigLIP-so400m frozen + 656K proj head）").

## Architecture

```
input image (224×224×3, [-1, 1] normalised)
    ↓ SigLIP-so400m vision tower (timm vit_so400m_patch14_siglip_224, FROZEN)
1152-d feature
    ↓ proj_head:  Linear(1152 → 512) → GELU → Linear(512 → 128)
128-d embedding
    ↓ L2 normalize
    ↓ InfoNCE with τ=0.07
```

**SigLIP source**: weights extracted from `vision_backbone.fused_featurizer.*`
of OpenVLA-7B-finetuned-libero-spatial safetensors (342 keys, 0 missing,
0 unexpected). This means our embeddings live in the **same feature space
OpenVLA's downstream LLM consumes** — directly transferable.

## Convergence Numbers

```
                 step 10         step 460        Δ
total InfoNCE     2.418           0.366         ↓ 2.05
L_mva (multi)     3.527           0.508         ↓ 3.02 (85.6% reduction)
L_tc  (temporal)  1.309           0.223         ↓ 1.09 (83.0% reduction)
random log(B=128) baseline: 4.852
recovery ratio: (4.852 - 0.366) / 4.852 = 92.5%
```

L_mva > L_tc throughout training, which matches intuition: cross-view
correspondence is harder than nearby-temporal correspondence (the latter
shares ~80% pixels in most LIBERO trajectories).

## Quantitative k-NN Retrieval Eval

The pretrained `proj_head` produces 128-d embeddings. We use them as a
search index over **all 6000 training frames** and ask: for each query
frame, do its nearest neighbors come from the same task / same episode?

```
                          recall@1   recall@5   recall@10   random@1
same-task hit              99.5%      99.9%      99.95%       2.75%   ← 36× over random
same-episode hit           91.4%      97.7%      99.0%        ~0.5%
same-task & |Δt|<=10       92.4%      98.2%      99.0%        ~0.3%
```

Per-suite breakdown (`recall@1 same-task`):

| suite | recall@1 |
|---|---|
| spatial | 99.3% |
| object | **100.0%** |
| goal | 99.3% |
| long10 | 99.5% |

Random baseline at recall@1 same-task = 2.75% (because each task has
~30 anchors out of 6000). **Our 99.5% is 36× over random**, a
near-perfect task-level discrimination.

The Object suite achieves perfect 100% recall@1 — fits with our
DoRA + DPO Object win on a different axis: this dataset has the
cleanest task-vs-task visual signal of all 4 suites.

Generated by `retrieval_eval.py` (5 min on 1× H20-3e, batch 64).

## How to Use

### Load the ckpt

```python
import torch
from code.pretrain.model import MultiViewProjectionHead
from code.pretrain.train import SiglipEncoderWrapper

# Encoder (frozen, point at any OpenVLA-7B safetensors directory)
encoder = SiglipEncoderWrapper("path/to/openvla-7b-finetuned-libero-spatial").cuda().eval()

# Projection head
proj = MultiViewProjectionHead(in_dim=1152, hidden=512, out_dim=128).cuda().eval()
ckpt = torch.load("models/pretrain_rlds_siglip_day8/proj_head.pt", map_location="cuda")
proj.load_state_dict(ckpt["proj_head"])

# Forward
def embed(images_BC HW):  # (B, 3, 224, 224) in [-1, 1]
    with torch.no_grad():
        feat = encoder(images_BCHW)        # (B, 1152)
        z = proj(feat)                      # (B, 128) L2-normalized
    return z
```

### Use cases

**1. Retrieval / nearest neighbor** — find semantically similar trajectory
   frames via cosine sim of `z`.

**2. Reward shaping** — `r_t = cos(z_agent_t, z_agent_goal)` as a dense
   surrogate reward for IL/RL pipelines that lack ground-truth task progress.

**3. Anomaly detection** — `z` distance from training distribution.

**4. Downstream init** — concat `proj_head(SigLIP(image))` as auxiliary
   feature into VLA fine-tunes (NOT yet ablated; Day 10 todo).

See `demo.ipynb` for a runnable example of (1).

## Limitations & Honest Notes

- **Dataset is small**: 50 episodes/suite (= ~12% of full LIBERO RLDS).
  Loss converges fully within 10 epochs precisely *because* the dataset
  is small. Scaling to 432 ep/suite would lower loss further and likely
  improve transfer.
- **No downstream ablation yet**: we have not yet confirmed that
  initialising OpenVLA's vision encoder with these features improves
  downstream LIBERO success rate. That's a Day 10 stretch goal — and
  there's a real chance it doesn't help (SFT on this exact data may
  already saturate the available signal). The contribution claim in
  the resume is purely on the **representation learning framework**,
  not on downstream gains.
- **Encoder is frozen**: by design — we wanted a lightweight head to
  stack on top of OpenVLA's existing vision tower without disturbing
  it. Unfreezing SigLIP would be a separate (~10× larger) experiment.
